# 要件定義書テンプレート

## 使い方

1. [要件定義基準](requirements-definition-standards.md)を読む。
2. [Prefix・要件定義書台帳](../specification-management/id-management-rules.md#prefix要件定義書台帳)へ、重複しない2〜4文字の大文字Prefixを登録する。
3. 「テンプレート本体」以下をコピーする。
4. `docs/requirements/<feature-name>/requirements.md` として保存する。
5. 要件IDを `<PREFIX>-F-001` から採番する。
6. `<...>` をすべて実値へ置き換える。決められない内容は「未確定事項」へ移す。
7. 不要な領域は空欄にせず「非該当」と理由を書く。
8. 着手可チェックを実行し、仕様責任者のレビューへ回す。

> テンプレート本体の `../../screen-design/...` リンクは、コピー先の `docs/requirements/<feature-name>/requirements.md` を基準にしている。このテンプレート原本上では解決しないが、指定の配置へコピーすると解決するため書き換えない。

## 着手可チェック

- [ ] 背景と目的が説明できる。

- [ ] 全機能要件に一意な要件IDがある。
- [ ] 全機能要件に検証可能な受け入れ条件がある。
- [ ] 正常系、異常系、キャンセル、権限差分、空状態、境界値を確認した。

- [ ] 非機能要件と依存関係を確認した。
- [ ] 着手ブロックが「はい」または「不明」の未確定事項がない。
