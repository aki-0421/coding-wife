# 画面一覧

この文書を画面IDの唯一の台帳とする。採番と廃止の判断は[ID管理ルール](../specification-management/id-management-rules.md)に従う。

## 画面とウィンドウの区別

- 画面IDは、ユーザーが達成する目的を識別する。
- Tauri window labelは、Window / WebViewとCapabilityの実行境界を識別する。
- Next.js path / view keyは、WebView内の表示・遷移を識別する。
- 1つのウィンドウに複数画面を配置してよい。
- OS標準ダイアログ、単純な確認ダイアログ、画面内状態には原則として画面IDを付けない。

## 登録時の確認

- [ ] 既存画面と目的が重複していない。
- [ ] 未使用の画面IDを採番した。
- [ ] window labelと画面IDを混同していない。
- [ ] Next.js path / view keyが未確定なら、その旨を記録した。
- [ ] 画面詳細仕様を作成した。
- [ ] 関連する要件定義書へ画面IDを追加した。
